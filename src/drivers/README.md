## src/drivers

```
│   ├── 📂drivers           # 드라이버 소스 코드
│   │   ├── 📄graphic.c         # 그래픽 드라이버
│   │   ├── 📄int.c             # 인터럽트 관리
│   │   ├── 📄keyboard.c        # 키보드 드라이버
│   │   ├── 📄mouse.c           # 마우스 드라이버
│   │   └── 📄timer.c           # 타이머 드라이버
```

하드웨어 드라이버 소스 코드입니다. <br>
지원하는 하드웨어 사양은 다음과 같습니다.
- CPU: intel 80386
- 그래픽: VGA
- 키보드/마우스: PS/2

각 장치는 32bit FIFO 버퍼를 통해 데이터를 주고 받습니다. <br>
- 타이머: `[0, 255]`
- 키보드: `[256, 511]`
- 마우스: `[512, 767]`
