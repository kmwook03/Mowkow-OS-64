## 커널 소스 코드 디렉토리

커널을 구성하는 소스 코드가 모여있는 디렉토리입니다.

```
📂src               # 커널 소스 코드
├── 📁boot              # 부트코드
├── 📁drivers           # 드라이버 소스 코드
├── 📂graphics          # 그래픽 관련 파일
│   └── 📁font
├── 📁include           # 헤더 파일        
├── 📁kernel            # 커널 구성 코드
└── 📁lib               # 라이브러리
```

| 디렉토리 이름 | 설명 |
|-|-|
| `📁boot` | 부트로더 소스 코드(`.nas`)  |
| `📁drivers` | 하드웨어 드라이버 소스 코드(`.c`) |
| `📁graphics/font` | 폰트 파일(`.FNT`, `.txt`) |
| `📁include` | 헤더 파일(`.h`) |
| `📁kernel` | 부트코드, 콘솔, 메모리 관리자 등 커널 소스 코드(`.c`, `.nas`) |
| `📁lib` | 한글, utf-8 등 라이브러리 소스 코드(`.c`) |
