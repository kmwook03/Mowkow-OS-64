# src/boot

```
├── 📂src               # 커널 소스 코드
│   ├── 📂boot              # 부트코드
│   │   ├── 📄asmhead.nas       # 시스템 초기화 및 32 비트 진입
│   │   └── 📄ipl.nas           # 부트 로더
```

## 세부 설명

### ipl.nas

디스크의 0번째 섹터에 위치할 부트로더입니다. <br>
`파일시스템 정의`/`세그먼트 레지스터 초기화 및 로딩 준비`/`디스크 읽기 최적화`로 구성되어있습니다.<br>
디스크에 위치한 커널을 메모리로 복사합니다.

### asmhead.nas

16비트 리얼 모드에서 32비트 보호 모드로 전환하기 위한 부트코드입니다.
화면 모드를 설정하고 하드웨어를 준비시키며 bootpack.c를 메모리로 불러와 C 커널을 실행시킵니다.
